# Measuring the Pulse of Prosperity: An Index of Economic Freedom Analysis

## 📌 Project Overview
This project analyzes the **Index of Economic Freedom (2022)** across countries and regions to understand how economic freedom varies globally and how it relates to key economic indicators such as unemployment rate. The analysis is performed using **Tableau** to create interactive visualizations, dashboards, and stories for data-driven insights.

---

## 🎯 Objectives
- To compare **economic freedom scores** across all countries  
- To analyze **region-wise economic freedom distribution**  
- To identify **top economically free countries**  
- To study the relationship between **economic freedom and unemployment rate**  
- To present insights using **interactive dashboards and stories**

---

## 📂 Dataset Description
**Dataset Name:** Index of Economic Freedom (2022)  
**Source:** Publicly available economic datasets  

### Key Attributes Used:
- Country Name  
- Region  
- Overall Economic Freedom Score (2022)  
- World Rank  
- Unemployment Rate (%)  
- GDP Growth, Tax Burden, Government Spending (supporting fields)

## 📖 Story Insights
- Europe and Americas show higher average economic freedom scores compared to other regions.
- Countries with higher economic freedom generally show **lower unemployment rates**.
- Economic freedom distribution highlights inequality across regions.
- Top ranked countries consistently perform well across multiple economic indicators.

## 🚀 How to Run the Project
1. Download **Tableau Desktop Public Edition**
2. Open Tableau and connect to `index_of_economic_freedom.csv`
3. Create worksheets using Country, Region, and Score fields
4. Build dashboards and add filters (Region, Country)
5. Create a Story using dashboards
6. Export dashboards and story as **PDF**
